APA SAJA FITUR TERBARU DI VERSI INI?
------------------------------------------------------------------------
1. Bloomberg Grade Stock Detail Modal (Pop-up Fundamental Saham):
   - Klik tombol [DETAIL] di hasil pencarian saham untuk membuka modal.
   - Klik nama saham mana pun di tabel "IDX WATCHLIST" atau di "HEATMAP DRILLDOWN"
     untuk langsung membuka modal fundamental saham tersebut.
   - 3 Tab Komprehensif:
     * OVERVIEW: Key Ratios (P/E, Forward P/E, P/B, EV/EBITDA, ROE, Dividend Yield, Market Cap, 52W High/Low).
     * FINANCIALS: Revenue, Operating Income, Net Income, Total Assets/Liabilities, Equity, Capex.
     * ANALYST: Konsensus analis (Strong Buy, Buy, Hold, Sell) & Target Harga (Mean, High, Low).
   - Tombol toggle [+ ADD TO WATCHLIST] / [- IN WATCHLIST] langsung dari dalam modal.
   - Animasi buka-tutup halus khas Bloomberg Terminal gelap.
   - Tombol ESC atau klik di luar modal untuk menutup.

2. Bloomberg Search Bar Saham IDX:
   - Pencarian real-time saham IHSG (.JK) via Yahoo Finance.
   - Rekomendasi saham populer (BBCA, BBRI, BUMI, AMMN, ADRO, TLKM, ASII).
   - Navigasi keyboard: Panah Atas/Bawah (↑ / ↓), Enter (↵), Escape (Esc).
   - Tombol [DETAIL] cepat di tiap baris hasil pencarian.

3. Dynamic Seasonality:
   - Memilih baris saham langsung mengarahkan ke tab SEASONALITY dengan histori 10 tahun.

CARA UPLOAD KE GITHUB (SANGAT MUDAH):
------------------------------------------------------------------------

OPSI 1: UPLOAD FOLDER VIA WEB GITHUB (DRAG & DROP)
1. Buka browser dan pergi ke repository GitHub Jarvis Anda:
   (Contoh: https://github.com/[username]/[repo-name])
2. Masuk ke folder proyek web Anda (biasanya `research-terminal/`):
3. Klik tombol "Add file" di pojok kanan atas -> pilih "Upload files".
4. Buka Finder di Mac Anda:
   Buka folder:
   /Users/iggerzefanyasurbakti/Documents/ANTIGRAVITY/READY_TO_DEPLOY/
5. Tarik (Drag & Drop) folder `app` dan `components` ke halaman GitHub tersebut.
6. Pada kolom commit message di bawah, ketik:
   "Feat: Add Bloomberg stock detail modal and integrate search & watchlist"
7. Klik tombol hijau "Commit changes".

OPSI 2: COPY-PASTE KODE SATU PER SATU (JIKA INGIN EDIT LANGSUNG DI GITHUB)
Jika ingin menimpa file lewat tombol pensil (✏️) di GitHub:
1. `READY_TO_DEPLOY/app/page.tsx`                   -> Timpa `app/page.tsx`
2. `READY_TO_DEPLOY/app/globals.css`               -> Timpa `app/globals.css`
3. `READY_TO_DEPLOY/app/api/stock-detail/route.ts`  -> Buat/timpa `app/api/stock-detail/route.ts`
