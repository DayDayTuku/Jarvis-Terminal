Fitur Baru yang Ditambahkan & Diperbaiki:
1. Search Bar Saham (StockSearch) bertema Bloomberg Terminal gelap, elegan, dan responsive.
2. Dropdown hasil pencarian rapi (tidak lagi berantakan/kebesaran warna biru).
3. Navigasi Keyboard lengkap: Panah Atas/Bawah (↑ / ↓), Enter (↵), Escape (Esc).
4. Klik di luar dropdown (Click-Outside) otomatis menutup dropdown.
5. Tombol silang (×) untuk reset text pencarian.
6. Rekomendasi saham populer IHSG saat input diklik pertama kali (BBCA, BBRI, BUMI, AMMN, ADRO, TLKM, ASII).
7. Memilih saham otomatis membuka tab "SEASONALITY" dengan ticker saham tersebut.
8. API Seasonality dinamis mendukung seluruh saham IDX (.JK) via Yahoo Finance.
